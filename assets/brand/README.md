# Brand assets

| File | Use |
| --- | --- |
| `helvax-logo-light.svg` | Full logo for light backgrounds (dark wordmark) |
| `helvax-logo-dark.svg` | Full logo for dark backgrounds (white wordmark) |
| `helvax-icon.svg` | App icon / favicon: red rounded square with white Swiss cross |

Colours: red `#D03B2B` (`#E0463A` for the "x" on dark), ink `#16130F`, white `#FFFFFF`.

The wordmark is Inter Display SemiBold (SIL Open Font License) converted to outlines, so no font is needed to display it. Regenerate with `python3 scripts/make_logo.py`.
