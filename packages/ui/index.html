.hx-incident with an orange mono uppercase strip. Use it for the one event that needs attention; everything else is a plain .hx-item.
Tags
.hx-tag are static labels in a list, not buttons. Use .hx-chip when they filter.

01 · Foundations

Tokens.One source for every value.

Every component reads from tokens.css. Change a token and the whole library follows; dark values are redefined on the same names, so no component carries its own theme logic.

Color

Orange is the signature, used for primary actions, focus and the one highlighted series in a chart. It is never used to mean danger. Click a swatch to copy its token.

Brand
Neutrals
Semantic (always paired with icon + label)
Contrast
brand-500 on white is 3.0:1, so it never carries small text. Use on-brand ink text on orange fills, and brand-700 for orange text on light surfaces.
Theme
Helvax is light only. Depth comes from warm stone panels and the grain gradients, not from a dark mode.

Typography

Plus Jakarta Sans for display, Inter for interface, IBM Plex Mono for every number a person compares. All three are SIL Open Font License; self-host the WOFF2 files in production with font-display: swap.

Surfaces separate with a 1px line first. Shadows are reserved for things that float: menus, toasts, dialogs.

Motion

150–250ms with one ease curve. Motion confirms an action; it never decorates. With reduced motion requested, every duration drops to zero and the hero pulse stops.

--ease: cubic-bezier(0.2, 0.7, 0.2, 1) for everything. Press a duration to compare.

Breakpoints & grid

12 columns on desktop, 8 on tablet, 4 on mobile. App shell components respond to their container, so the same sidebar works in a full page or a narrow preview.

Desktop · ≥ 1280px · 12 col · 24px gutter
Tablet · 640–1279px · 8 col · 20px gutter
Mobile · < 640px · 4 col · 16px gutter

Icons

Drawn on a 20px grid with a 1.75 stroke and round joins, inheriting currentColor. Abstract signals over padlocks and hooded figures. Decorative icons get aria-hidden; icon-only buttons get an aria-label.

02 · Actions & inputs

Controls.Soft to touch, clear to use.

Every control has a 44px hit area, a visible focus ring and a disabled state that still explains itself.

Button .hx-btn

Orange primary for the one main action on a screen, dark secondary for confident alternatives, outline and ghost for the rest.

Variants
--soft (light grey pill) --secondary (ink) --outline --ghost --destructive · sizes --sm --lg · --icon --block
HTML
<button type="button"> for actions, <a class="hx-btn"> for navigation. Never a div.
Keyboard
Tab to focus, Enter or Space to activate (native).
States
Primary carries a soft orange glow that lifts on hover; active nudges 1px. Loading sets aria-busy="true" and disabled via HelvaxUI.setLoading(btn, true); the label is kept for screen readers. Disabled at 45% opacity.
A11y
Primary uses ink text on orange (5.8:1). Icon-only buttons need aria-label. Destructive actions confirm in a Dialog.

Link .hx-link

Inline links are always underlined so they never rely on color alone.

Read how we separate scanner visits from human clicks, or open the October report.

Browse the scenario library
Variants
default (brand-700), --quiet (ink), --arrow (standalone call to action)
A11y
Link text names the destination. External links add rel="noopener" and a visually hidden "(opens in new tab)".

Input .hx-field · .hx-input

Label above, help below, error replaces help and says how to fix it.

Shown to admins in reports. Employees never see it.
Add the top-level domain, for example kessler-wohnbau.de.
Set at provisioning and cannot be changed.
HTML
<label for> + <input>; help and error linked with aria-describedby.
States
hover, focus (orange halo), aria-invalid="true" (red border + message), disabled (sunken).
A11y
Never use the placeholder as the label. Error text starts with what to do. Mark optional fields, not required ones.

Select .hx-select

A native select, restyled. It keeps the platform picker on mobile and full keyboard support for free.

Send times stay random inside business hours.
Keyboard
Native: ↑ ↓ to change, Space to open, type to jump.
When not to use
More than about 15 options needs a searchable combobox; fewer than 4 reads better as Radio.

Checkbox & Radio .hx-check

Native inputs with a custom face, so forms submit and validate as usual.

Scenario categories
Report language
HTML
Wrap the input in its <label>; group with <fieldset> and <legend>. Indeterminate is set from script (input.indeterminate = true).
Keyboard
Space toggles a checkbox; arrows move within a radio group.

Switch button[role=switch]

For settings that take effect immediately. If it needs a Save button, use a Checkbox.

Events
Fires hx:change with detail: true|false.
Keyboard
Space or Enter toggles. The visible text is the accessible name.

DateRangePicker [data-hx-daterange]

Presets for the common periods, two native date fields for anything else. Validates that the end follows the start.

Reporting period

Attributes
data-today pins "today" (for tenant timezone or tests). Presets: 7 30 90 month lastmonth.
Events
hx:range with { from, to, valid } as ISO dates.
A11y
Presets are toggle buttons (aria-pressed). The summary is a polite live region and also carries the error.

UploadDropzone [data-hx-dropzone]

For the employee roster import. Drop or browse; the file is checked for type, size and an email column before the dry run.

Nothing is sent until you confirm the dry-run results.

    HTML
    A <label> wrapping a real file input, so click, keyboard and screen readers work without script.
    States
    idle, data-dragging, data-state="error" (wrong type or too large), file list with row count or warning.
    Events
    hx:file with { file, error } per file.

    04 · Overlays & navigation

    Navigation.Always know where you are.

    Overlays use native <dialog> for focus handling and Escape. Navigation marks the current place with aria-current.

    Tooltip & Popover .hx-tooltip · [data-hx-popover]

    Tooltips add a short explanation on hover and focus. Popovers hold interactive content such as a quick confirmation.

    A visit with real browser interaction after scanner screening. Link prefetches are counted separately. Confidence 0.62Model confidence for this reply class. Below 0.7 goes to human review.
    Pause all simulations for this tenant? Scheduled sends are held. You can resume at any time.
    Keyboard
    Tooltip shows on focus; Esc hides it (WCAG 1.4.13). Popover opens on click, moves focus inside, closes on Esc or outside click and returns focus.
    Rules
    Tooltips hold no links or buttons and are never the only place information lives. Use the popover for anything clickable.

    Dialog dialog.hx-dialog

    Modal decisions, mainly confirmations for actions that are hard to undo.

    Every queued send for all 38 tenants is held immediately. Tenant admins see a banner until you resume. This is logged to the audit trail.
